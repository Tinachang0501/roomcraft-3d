## 📸 廠商自訂材質照片即時 3D 貼圖
- 支援直接上傳廠商提供的**地磚、木地板、微水泥、壁紙或布料樣本照片**。
- 可選擇套用至：
  1. **3D 地坪 (Floor)**
  2. **3D 主牆面 (Wall)**
  3. **3D 家具布料 (Furniture)**
- 系統自動建立 Repeat Wrapping 3D 紋理貼圖，並自動採樣主色調更新至 60-30-10 配比儀表板。

## 🪑 自訂家具實物照片與真實尺寸配比規劃模擬
- **放入家具照片**：上傳手機在門市（如 IKEA、無印、家具行）實拍的沙發、茶几、床或餐桌照片。
- **輸入實際公分尺寸**：填入長度 (L)、寬度/深 (W)、高度 (H) cm。
- **即時空間佔比診斷**：
  - 精確計算家具佔地面積 ($m^2$) 與佔房間總面積百分比 ($X\%$)。
  - 智能判讀尺度狀態（黃金尺度配比、尺寸偏大警示、尺度偏小留白多）。
  - 自動換算剩餘通行走道寬度（例如：預估剩餘動線 85cm，高於人體工學標準 75cm 通行順暢）。
- **2D 等比例平面配置圖**：在 Canvas 上以真實比例繪製房間與家具實物照片，並標註公分尺寸與動線箭頭線，支援一鍵下載效果圖 PNG！
- **3D 空間真實比例投放**：點擊「在 3D 空間中投放此家具」，3D 空間立即生成等比例實物家具量體，可切換 360° 旋轉或走進去漫遊檢視！

## 🚀 啟動方式
- **直接點擊啟動**：在資料夾中雙擊執行 `start.bat`，瀏覽器自動開啟 `http://localhost:3000`。
- **免安裝離線開啟**：亦可直接用 Chrome 或 Edge 瀏覽器打開 `index.html`。
